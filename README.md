# AxCore
Minecraft plugin that adds all essential commands to a minecraft server

---
## Commands & Permissions
- `/buydrill` - `axcore.buydrill`
- `/day` - `axcore.day`
- `/dispose` - `axcore.dispose`
- `/feed` - `axcore.feed`
- `/fly` - `axcore.fly`
- `/flyspeed` - `axcore.flyspeed`
- `/gm` - `axcore.gamemode`
- `/heal` - `axcore.heal`
- `/hologram` - `axcore.hologram`
- `/motd` - `axcore.motd`
- `/night` - `axcore.night`
- `/ping` - `axcore.ping`
- `/weather` - `axcore.weather`
